>>===== MODE =====>>
citation
<<===== MODE =====<<


>>===== DESCRIPTION =====>>
Regression test for given-name disambiguation when the citation's names element
is defined in a macro. The initials setting in the macro must be found when
disambiguating names.
<<===== DESCRIPTION =====<<


>>===== RESULT =====>>
Asthma, Bosworth Bronchitis and C. Cold (1980); Asthma, Beauregarde Bronchitis and O. Cold (1995)
<<===== RESULT =====<<
