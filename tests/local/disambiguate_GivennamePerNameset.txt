>>===== MODE =====>>
citation
<<===== MODE =====<<


>>===== DESCRIPTION =====>>
An editor given-name clash under the all-names rule should not force given-name
expansion on unambiguous authors in a separate names element.
<<===== DESCRIPTION =====<<


>>===== RESULT =====>>
J. Doe (Alan Smith); J. Roe (Alice Smith)
<<===== RESULT =====<<
